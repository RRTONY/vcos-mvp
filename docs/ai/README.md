# AI Knowledge Base

Background notes for any AI tool working on VCoS. The **rules** live in
[`/AGENTS.md`](../../AGENTS.md); these notes explain the agreed behaviour and the reasons behind
it.

**Start here:** [TASK_GUIDE.md](TASK_GUIDE.md) (what kind of request, where it lives, ask first?)
and [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) (where everything is). Keep both current.

- Read the note for the area you are about to touch before changing it.
- When you learn something new (a rule the team agreed, a gotcha, a fixed bug), update the
  matching note or add one here, with a line in this index. Not in a private memory folder.
- Never put passwords, tokens or keys in these files.
- Notes are dated. If a note conflicts with the code, the code wins: check, then fix the note.
